## 代理树初始列数 2 → 应 3（三三展示）
- 根因：`src/components/proxy/proxy-group-tree.tsx` 的 `width`/`rightWidth` 初始写死 420；`fitColumns(420,4)`（`NODE_W_MIN=148`、`CELL_GAP=8`）算出 2 列，3 列需要右栏宽度在 [484,640)。更关键的是树 YAML 走 `useQuery` 异步加载，首帧 `tree.groupNames.length===0` 时左右栏 DOM 根本不渲染，而挂 `ResizeObserver` 的 `useLayoutEffect(..., [])` 此时 `leftRef.current===null` 直接 return，之后不再重挂 → 宽度永远停在 420。切页面回来时数据已缓存、DOM 首帧存在，观察器才挂上 → 变成 3 列。
- 修复（同文件）：新增 `estimatePaneWidth()` = `max(420, min(620, floor(innerWidth/2)))`，两个 width state 用它做懒初始化（620 → fitColumns 得 3 列，实测 634 也得 3，640 会变 4 所以要 clamp）；`useLayoutEffect` 依赖改为 `[hasTree]`（`hasTree = tree.groupNames.length > 0`），DOM 就绪后重挂观察器，并把测量抽成 `measure`。注意不要在 effect 里同步调 `measure()`，会触发 `@eslint-react/set-state-in-effect` 警告（pre-commit 用 `--max-warnings=0` 会挂），靠 RO 的首次回调即可（本帧绘制前送达）。
- 顺带修 `src/components/proxy/use-window-width.ts`（普通代理列表 `calculateColumns` 的宽度源）：原来只在 `window resize` 时更新且初值取 `document.body.clientWidth`，侧栏收起等布局变化抓不到；改为初值 `window.innerWidth` + `useLayoutEffect` 里用 `ResizeObserver` 观察 body/documentElement + resize 兜底，setState 用值相等时返回 prev 防循环。1280 宽 → `calculateColumns` 得 3 列。
- 验证：`pnpm typecheck`、eslint 两文件、Biome format（hook 已转 CRLF）通过。注意 `proxy-group-tree.tsx` 1397-1428 行有既存的 Biome 格式漂移（与本次改动无关），提交时 `biome format --write` 会自动重排那几行。
